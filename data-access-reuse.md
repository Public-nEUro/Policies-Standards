# Data access

Data can be seen in the [PublicnEUro catalogue](https://publicneuro.eu/catalogue.html).

Some datasets are Open Access. Users can simply click on download to gain browser access to the data. To use our CLI, users need to be registered.

Most datasets are access controlled. To gain access, users must:

- be registered
- accept the Data User Agreement of the requested dataset
- request the dataset online

# User registration

Human neuroimaging data may remain personal data after pseudonymisation and therefore legal contracts (i.e., data-user agreements) must be set up between authors and users, which in turn implies that users must be identifiable.

## For non-EU country users

To transfer EU personal data outside EU, unless the user is in a country on the list of [adequacy countries](https://commission.europa.eu/law/law-topic/data-protection/international-dimension-data-protection/adequacy-decisions_en), someone from the legal department at the user institution must agree and sign the EU standard contractual clauses (available here: [SCC_controler2controler.docx](https://publicneuro.eu/SCC_controler2controler.docx)).

## Identification

Someone from the PublicnEUro team will (1) check the user is really affiliated to the institution with an internet search (or ask user to give a link to their staff/student profile) and (2) do a video call to explain data privacy related to the data and also how we store personal user information. A screen shot of the user ID is taken and stored on NRU server in an encrypted and password protected archive.

# Dataset-specific conditions

Each dataset is governed by the Data controller. Data controllers decide on Open Access or Controlled access (with/without geo-restriction) as per contract between NRU and the Data controller.

## Access Approval

Each controlled access dataset comes with a Data User Agreement that sets the licensing terms between authors/data controller and users. Registered users can request access to a dataset after signing the DUA. Depending on the Data Controller policy, PublicnEUro can deliver immediate access after online signing ('click and download') or access is given after approval from the Data controller ('upload signed DUA and await approval').

## Reuse

Data reuse is governed by the licensing/DTA terms.
